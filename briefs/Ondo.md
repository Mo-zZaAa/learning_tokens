# Ondo 브리핑
- 축 : 경쟁 거래소까지 유통처로 삼고 자신은 발행에만 집중
- 가설 : 1등 집중, 자기 거래소 없이 발행만 하고 판매는 남의 거래소와 지갑에 맡김

## 1층 (키워드)
- 본업 : 국채 토큰 OUSG(미국 적격투자자), USDY(미국 밖 개인과 기관), 잔액 USDY 19.7억 달러, OUSG 3.13억 달러
- 시작 : 국채 토큰 직접 발행(2023-01 OUSG, 2023-08 USDY)
- 붙인 것 : 2024-08 OUSG 기초자산 BlackRock BUIDL(파트너) → 2025-09 미국 밖 주식 토큰 Ondo Stocks(직접) → 2025-09 유통 Bitget, OKX, Trust Wallet(파트너) → 2025-10 미국 증권사, ATS, 명의개서 Oasis Pro(인수) → 2025-10 BNB 체인, 2026-01 Solana 상장(직접) → 2026-02 유통 Binance Alpha, Binance Wallet(파트너) → 2026-04 의결권 Broadridge(파트너) → 2026-07 DTCC(파트너) → 2026-09 BlackRock 포트폴리오 3종(파트너) → 2026-10 비상장사 토큰(직접)
- 지금 하는 것 : 국채 토큰과 미국 밖 주식 토큰 450종 이상을 남의 거래소, 지갑에 공급(Ondo Stocks 보유자 186,636명, 잔액 8.99억 달러)
- 해외 진출 : 인가 없이 판매 중(미국 밖 전반), EEA는 투자설명서 승인(직접, 2026-11-11 유효기간 종료), UAE는 Nest Exchange(파트너)

## 2층 (받치는 사실)
- 국채 토큰 잔액 : USDY 발행 잔액 19.7억 달러(2026-11-13 회사 화면) [F-1318](https://ondo.finance/usdy), OUSG 3.13억 달러(2026-11-13 회사 화면) [F-1315](https://ondo.finance/ousg), 국채 토큰 플랫폼 2위 32억 달러, 1위 Franklin Benji 33억 달러(rwa.xyz 제3자 집계, 2026-11-16) [F-1321](https://app.rwa.xyz/treasuries)
- 시작 : OUSG 2023-01 출시 [F-1150](https://ondo.finance/blog/announcing-tokenized-us-treasuries-and-bonds), 적격투자자 전용 [F-0532](https://docs.ondo.finance/legal/ondo-summit-terms/keynote-disclaimers), USDY 2023-08-03 비미국 개인과 기관 대상 [F-1151](https://ondo.finance/blog/introducing-ondo-usd-yield-usdy)
- BlackRock BUIDL : 2024-08 OUSG 기초자산을 BUIDL로, Circle USDC 즉시 유동성으로 24시간 발행, 상환 [F-1317](https://ondo.finance/blog/building-on-buidl-how-ondo-leverages-blackrocks-tokenized-treasuries)
- 주식 토큰 : 2025-09 100종 이상 출시, 미국 투자자 제외 [F-0197](https://decrypt.co/337944/ondo-100-tokenized-stocks-ethereum), 지금 450종 이상(회사 페이지, 2026-11-16) [F-0477](https://ondo.finance/ondo-stocks)
- 출시 유통 파트너 : Bitget, Trust Wallet, OKX, HTX Global, 1inch [F-0572](https://docs.ondo.finance/ondo-stocks/overview), Bitget은 100종 이상에 98종 추가 [F-0202](https://cfotech.news/story/bitget-widens-ondo-tokenised-stocks-etfs-metals)
- Binance : 2026-02-24 Binance Alpha와 Binance Wallet에 10종 상장(코인텔레그래프 보도) [F-0201](https://cointelegraph.com/news/binance-alpha-ondo-tokenized-stocks-etfs), UAE에서 Binance 운영 Nest Exchange 거래 허용 [F-0549](https://docs.ondo.finance/ondo-stocks/important-notes)
- Oasis Pro 인수 : 2025-10-07 완료, SEC 등록 증권사, ATS, 명의개서대리인 자격 [F-1216](https://ondo.finance/blog/ondo-acquires-oasis-pro), 2026-07 미국 보관형 IVV, MU 2종 첫 가동 [F-1128](https://ondo.finance/blog/ondo-launches-tokenized-securities-in-usa)
- 대형 금융사 제휴 : Broadridge 2026-04-28 [F-0463](https://ondo.finance/), DTCC 2026-07-15 [F-1049](https://ondo.finance/blog/ondo-and-dtcc-collaborate-on-tokenized-stocks), BlackRock 전략 포트폴리오 3종 2026-09-24 [F-1324](https://ondo.finance/blog/introducing-ondo-intelligent-portfolios)
- 지금 규모 : 2026-08-15 전체 보유자 200,645명, Ondo Stocks 186,636명(회사 보도자료) [F-1390](https://www.prnewswire.com/apac/news-releases/ondo-stocks-surpasses-1-billion-in-value-as-ecosystem-surges-302852162.html), 주식 토큰 잔액 8.99억 달러, 점유율 24.23%(rwa.xyz 제3자 집계, 2026-11-16) [F-1022](https://app.rwa.xyz/stocks)
- 해외 : 미국 밖은 Regulation S(미국 밖 비미국인 판매는 미국 공모 등록 불요) 면제 [F-0560](https://docs.ondo.finance/ondo-stocks/legal-and-regulatory), BVI 감독기관 등록, 인가 없음 [F-0528](https://docs.ondo.finance/legal/terms-of-service), EEA는 리히텐슈타인 FMA 투자설명서 승인 2025-11-11, 29개국 통지, 유효기간 2026-11-11 [F-1240](https://www.fma-li.li)

- Q : 주식 토큰은 법적으로 무엇인가 / A : BVI 발행 법인의 채무증권, 스위스법 적용, 기초 종목 1:1 추종 [F-0187](https://www.mfsa.mt/wp-content/uploads/2026/01/Ondo-Global-Markets-BVI-Limited-Final-Terms-Document-dated-11-November-2025.pdf). 기초 주식 인도 청구 불가, 담보 범위에서만 상환받는 채무 [F-0188](https://www.mfsa.mt/wp-content/uploads/2026/01/Ondo-Global-Markets-BVI-Limited-Final-Terms-Document-dated-11-November-2025.pdf)
- Q : USDY는 스테이블코인인가 / A : 아님. 토큰화 담보부 노트(발행사 채무증서) [F-0509](https://docs.ondo.finance/general-access-products/usdy/comparison-stablecoins)
- Q : Oasis Pro 인수 세부는 / A : 금액 비공개, 목적은 증권사, ATS, 명의개서대리인 인가를 한꺼번에 얻어 미국 투자자에게 판매(The Block 보도) [F-1392](https://www.theblock.co/news/deals/2025-07-04-ondo-finance-to-acquire-us-regulated-broker-oasis-pro-for-tokenized-securities-expansion-361120)
- Q : 경영 리스크는 / A : 창업자 겸 CEO Nathan Allman 2026-05 사망, Ian De Bode 승계 [F-0207](https://forklog.com/en/power-struggle-emerges-at-ondo-finance-following-founders-death/). 2026-08 유족이 델라웨어 법원에 경영권 소송, 결과는 확인하지 못함 [F-0208](https://forklog.com/en/power-struggle-emerges-at-ondo-finance-following-founders-death/)
- Q : 숫자의 출처 등급은 / A : 보유자 수는 회사 보도자료 [F-1390](https://www.prnewswire.com/apac/news-releases/ondo-stocks-surpasses-1-billion-in-value-as-ecosystem-surges-302852162.html). Bitget 안 Ondo 비중 2025-12 약 73%에서 89%는 Bitget 발표, 산정 방식 비공개 [F-0203](https://cfotech.news/story/bitget-widens-ondo-tokenised-stocks-etfs-metals). USDY는 회사 화면 19.7억 달러와 rwa.xyz 23.95억 달러가 서로 다르며 하나로 고르지 않음 [F-1322](https://app.rwa.xyz/treasuries)
