# 브리핑 1층 한눈에 (2026-11-17)

회사별 전체(2층 받치는 사실, 3층 꼬리질문)는 briefs/<회사>.md.

## Kraken
- 축 : 인수로 미국 파생 인가 한 벌과 주식 토큰 발행사까지 사서, 선물과 주식 토큰을 발행부터 청산까지 한 그룹 안에서 처리
- 가설 : 다 한다, 거래, 은행, 자산관리, 기업용 인프라 네 기둥을 동시에 넓히고 현물 점유율 6.5%로 1등 아님

- 시작 : 가상자산 현물 거래소(2011, 모회사 Payward)
- 붙인 것
  - 파생 : Crypto Facilities(2019), NinjaTrader, Small Exchange, Bitnomial(모두 인수)
  - 주식, 주식 토큰 : 미국 주식(직접) → xStocks 판매(파트너) → 발행사 Backed(인수) → 해외 상장주 GTN(파트너)
  - 은행, 결제 : 와이오밍 은행 인가(직접), Reap(인수), EU 은행 Saldo(인수)
  - 기업, 기관용 : Embed, Prime(직접), 시장감시 Nasdaq(파트너)
  - 해외 인가 : 버뮤다 파생 거래장(직접), 키프로스 투자회사(인수)
- 지금 하는 것 : 거래, 은행, 자산관리, 기업용 인프라(2026 Q3 플랫폼 거래량 3,530억 달러, 총플랫폼마진 4.87억 달러)
- 해외 진출
  - 미국 밖 여러 나라 : 버뮤다 법인으로 판매(판매국 인가 없음)
  - EU : 직접 인가(아일랜드) + 인수(키프로스)
  - 홍콩, 영국, EU 상장주 : 파트너(GTN), 독일 파트너(360X)
  - 아시아태평양 결제 : 인수(Reap)

## Coinbase
- 축 : 직접 인가가 중심이고 빈 곳만 인수로 메워 현물 거래소에 선물과 옵션을 붙여, 거래대금 대부분이 파생
- 가설 : 다 한다, 회사가 2026 우선순위 1로 암호자산, 주식, 예측시장, 원자재, 외환을 한 곳에서 거래(Everything Exchange)를 명시

- 시작 : 가상자산 현물 거래(2012), 미국 개인
- 붙인 것
  - 파생 : 선물 거래소 FairX(인수), 선물 중개(직접), 옵션 Deribit(인수), 청산소(직접)
  - 기관 : 보관 신탁 인가(직접), Prime(인수)
  - 스테이블코인 : USDC(파트너 Circle)
  - 주식, 예측시장 : 미국 주식(직접), 예측시장 Kalshi(파트너), 주식 토큰 아부다비 발행(직접)
  - 인가 : 뉴욕주 BitLicense, 버뮤다, EU MiCA(모두 직접)
- 지금 하는 것 : 현물, 선물, 옵션, 예측시장, 주식, 스테이블코인, 보관(2026 Q3 거래대금 1조 2,138억 달러 중 파생 약 81%, 총매출 12.2억 달러)
- 해외 진출
  - EU(룩셈부르크), 영국, 버뮤다, 아부다비 : 직접 인가
  - 미국 밖 기관 파생 : 인수(Deribit)
  - 미국 밖 개인 주식 토큰 : 인가 없이 판매(Base DeFi 유통)

## Robinhood
- 축 : 같은 개인 고객에게 상품을 계속 얹어 키움(주식, 옵션, 가상자산, 선물, 자문, 비상장). 예측시장은 예시 하나(파트너 Kalshi로 먼저 열고 MIAXdx 인수로 직접 운영)
- 가설 : 다 한다, 같은 고객 계좌에 중개, 가상자산, 자문, 은행, 비상장 접근을 함께 제공(회사 소개 문장)

- 시작 : 미국 개인 주식 중개 앱(무수수료), 자체 청산
- 붙인 것
  - 거래 상품 : 옵션, 가상자산(직접), 선물(인수), 24시간 주식(파트너 Blue Ocean)
  - 예측시장 : Kalshi(파트너) → 거래소와 청산소 MIAXdx(인수)
  - 자문 : 자문사 수탁 TradePMR(인수), 관리계좌 Strategies(직접)
  - 비상장, 기타 : 비상장 펀드 RVI(직접), 자체 체인(직접)
- 지금 하는 것 : 개인 종합 투자 앱(옵션, 이벤트 계약, 주식, 가상자산, 자문), 2026 Q3 순매출 14.2억 달러, 펀디드 고객 2,870만 명
- 해외 진출
  - EU : 직접 인가(리투아니아) + 인수(Bitstamp)
  - 영국 : 직접 / 캐나다 : 인수(WonderFi) / 싱가포르, 두바이 : 직접 인가(미출시)
  - 그 밖 120여 개국 : 인가 없이 판매(지갑판 주식 토큰)

## Binance
- 축 : 아부다비에 인가를 모아 거점으로 삼고, 기존 거래소 이용자에게 주식을 거래소 상품으로 붙임(실물 미국 주식 → 자체 발행 bStocks)
- 가설 : 1등 집중, 은행, 자문, 비상장 같은 다른 업 없이 주식도 거래소 상품(현물, 담보, 무기한선물)으로만 붙임

- 시작 : 가상자산 거래소
- 붙인 것
  - 첫 시도 : 주식 토큰(파트너 CM-Equity, 2021 종료)
  - 거점 인가 : 아부다비 거래소, 청산소, 중개(직접)
  - 주식 거래소 상품 : 남이 발행한 토큰(파트너 Ondo) → 실물 미국 주식(직접) → bStocks 발행, 담보, 무기한선물(직접)
- 지금 하는 것 : 가상자산 거래소 + 주식 거래소 상품, 2025 거래대금 34조 달러, bStocks 운용자산 10억 달러 초과
- 해외 진출
  - 아부다비 : 직접 인가(거점) / 두바이 : 직접 인가
  - 한국 : 인수(고팍스) / 아르헨티나 : 등록 + 현지 파트너
  - 그 밖 100여 개국 : 거래소 직접 판매(나라별 인가 근거 없음), 미국은 bStocks 판매 제외

## Dinari
- 축 : 증권사 역할을 대신하는 API로 핀테크 앱을 판매 창구로 붙여, 자기 고객 화면 없이 미국 주식 토큰을 대는 B2B 공급사
- 가설 : 둘 다 아님, 주식 토큰 B2B 공급 하나에 집중하나 그 영역 1등 아님(발행 잔액 1,520만 달러)

- 미국 안 판매 자격 : 명의개서대리인 Dinari, Inc. SEC 등록(2022-05), 증권사 Dinari Securities 등록(2025-06, 53개 주와 영토)
- 시작 : 미국 밖 개인용 미국 주식 토큰 dShares(2023-08), 종목 20종
- 붙인 것
  - 판매 창구 : 핀테크 앱 Meru, Cadana, Fasset(2024-07), 1exchange, Bitcoin.com 지갑, Hyperliquid, 증권사 채널 tZERO(모두 파트너)
  - 공급 기능 : 기업용 API(직접, 2024-02), 미국판 724종과 미국 증권사 API(직접, 2026-08)
  - 거래 지원 : 입금 Ramp, Transak, 24시간 호가 Flow Traders, 의결권 Broadridge(모두 파트너)
  - 자체 인프라 : 달러 토큰 USD+, 자체 체인 DFN(직접)
- 지금 하는 것 : 핀테크 앱, 지갑, 증권사에 미국 주식 토큰 공급(724종 이상, 발행 잔액 1,520만 달러)
- 해외 진출
  - 현지 파트너 앱이 고객 담당(60개국 이상)
  - 자체 현지 인가 근거 없음

## Ondo
- 축 : 경쟁 거래소까지 유통처로 삼고 자신은 발행에만 집중
- 가설 : 1등 집중, 자기 거래소 없이 발행만 하고 판매는 남의 거래소와 지갑에 맡김

- 본업 : 국채 토큰 OUSG(미국 적격투자자), USDY(미국 밖 개인과 기관), 잔액 USDY 19.7억 달러, OUSG 3.13억 달러
- 시작 : 국채 토큰 직접 발행(2023-01 OUSG, 2023-08 USDY)
- 붙인 것
  - 자산 : 주식 토큰 Ondo Stocks(직접, 2025-09), BlackRock 포트폴리오 3종(파트너), 비상장사 토큰(직접)
  - 유통처 : Bitget, OKX, Trust Wallet(2025-09), Binance Alpha와 Wallet(2026-02)(모두 파트너)
  - 미국 판매 자격 : Oasis Pro 증권사, ATS, 명의개서(인수, 2025-10)
  - 인프라 : BlackRock BUIDL, 의결권 Broadridge, DTCC(파트너), BNB 체인, Solana(직접)
- 지금 하는 것 : 국채 토큰과 미국 밖 주식 토큰 450종 이상을 남의 거래소, 지갑에 공급(Ondo Stocks 보유자 186,636명, 잔액 8.99억 달러)
- 해외 진출
  - 미국 밖 전반 : 인가 없이 판매
  - EEA : 투자설명서 승인(직접, 2026-11-11 유효기간 종료)
  - UAE : Binance 운영 Nest Exchange(파트너)
