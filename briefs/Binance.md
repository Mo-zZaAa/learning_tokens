# Binance 브리핑
- 축 : 아부다비에 인가를 모아 거점으로 삼고, 기존 거래소 이용자에게 주식을 거래소 상품으로 붙임(실물 미국 주식 → 자체 발행 bStocks)
- 가설 : 1등 집중, 은행, 자문, 비상장 같은 다른 업 없이 주식도 거래소 상품(현물, 담보, 무기한선물)으로만 붙임

## 1층 (키워드)
- 시작 : 가상자산 거래소
- 붙인 것 : 주식 토큰 첫 시도(파트너 CM-Equity) → 아부다비 거래소, 청산소, 중개 인가(직접) → 남이 발행한 주식 토큰(파트너 Ondo) → 실물 미국 주식(직접) → 자체 발행 bStocks(직접) → bStocks 담보(직접) → 주식 무기한선물(직접)
- 지금 하는 것 : 가상자산 거래소 + 주식 거래소 상품, 2025 거래대금 34조 달러, bStocks 운용자산 10억 달러 초과
- 해외 진출 : 아부다비 직접 인가(거점) / 두바이 직접 인가 / 한국 인수(고팍스) / 아르헨티나 직접 등록 + 현지 파트너 / 그 밖 100여 개국 거래소 직접 판매(나라별 인가 근거 없음) / 미국 bStocks 판매 제외
