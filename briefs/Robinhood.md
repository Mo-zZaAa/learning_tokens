# Robinhood 브리핑
- 축 : 같은 개인 고객에게 상품을 계속 얹어 키움(주식, 옵션, 가상자산, 선물, 자문, 비상장). 예측시장은 예시 하나(파트너 Kalshi로 먼저 열고 MIAXdx 인수로 직접 운영)
- 가설 : 다 한다, 같은 고객 계좌에 중개, 가상자산, 자문, 은행, 비상장 접근을 함께 제공(회사 소개 문장)

## 1층 (키워드)
- 시작 : 미국 개인 주식 중개 앱(무수수료), 자체 청산
- 붙인 것 : 옵션(직접) → 가상자산(직접) → 24시간 주식 거래(파트너 Blue Ocean) → 선물(인수) → 자문사 수탁 TradePMR(인수) → 예측시장(파트너 Kalshi) → 관리계좌 자문 Strategies(직접) → 예측시장 거래소와 청산소 MIAXdx(인수) → 비상장 펀드 RVI(직접) → 자체 체인(직접)
- 지금 하는 것 : 개인 종합 투자 앱(옵션, 이벤트 계약, 주식, 가상자산, 자문), 2026 Q3 순매출 14.2억 달러, 펀디드 고객 2,870만 명
- 해외 진출 : EU 직접 인가(리투아니아) + 인수(Bitstamp) / 영국 직접 / 캐나다 인수(WonderFi) / 싱가포르, 두바이 직접 인가(미출시) / 그 밖 120개국 이상 인가 없이 판매(지갑판 주식 토큰)

## 3층 (꼬리질문 대비)
- Q : 예측시장을 왜 직접 운영으로 옮겼나, 조건은? / A : 예측시장이 매출 기준 가장 빨리 크는 상품이 되어 거래소와 청산소를 직접 보유. 2025-11-25 Susquehanna와 합작 발표, Robinhood 지배, Susquehanna 유동성 공급, MIAX 지분 10% 유지 [F-1383](https://robinhood.com/us/en/newsroom/robinhood-prediction-markets-joint-venture)
- Q : 인수 금액은? / A : Bitstamp 약 2.24억 달러 전액 현금 [F-0606](https://investors.robinhood.com/node/16931/html), WonderFi 약 1.78억 달러 전액 현금 [F-0609](https://investors.robinhood.com/node/16931/html). Bitstamp 인수 이유는 미국 밖 확장과 기관 사업 확보 [F-1197](https://www.robinhood.com/us/en/newsroom/robinhood-to-acquire-bitstamp)
- Q : 선물은 직접 받은 인가인가? / A : 아님. 2010년 FCM 등록된 옛 Marex North America 법인을 넘겨받아 Robinhood Derivatives로 씀, 넘겨받은 시점은 공개 자료에 없음 [F-1236](https://www.nfa.futures.org/BasicNet/#0424278)
- Q : 주식 토큰의 법적 구조는? / A : 지갑판은 저지 발행사 RHJ에 대한 채무증권, 주식 소유 없음 [F-0992](https://cdn.robinhood.com/assets/robinhood/legal/rhj_base_prospectus.pdf). EU판은 Robinhood Europe과 맺은 파생계약 [F-0993](https://cdn.robinhood.com/assets/robinhood/legal/eu-crypto-user-agreement.pdf), 회사 파산 시 원금 전액 손실 가능 고지 [F-0652](https://robinhood.com/eu/en/invest)
- Q : 제재 이력은? / A : 2025-01 SEC 합의 과징금 총 4,500만 달러 [CASE-005](https://www.sec.gov/newsroom/press-releases/2025-5), 2025-03 FINRA 벌금 2,600만 달러와 고객 환급 375만 달러 [CASE-006](https://www.finra.org/media-center/newsreleases/2025/finra-orders-robinhood-financial-pay-375-million-restitution), 2024-12 미인가 영업으로 네브래스카, 매사추세츠 벌금 [F-0598](https://investors.robinhood.com/node/16931/html)
- Q : OpenAI 토큰 논란은? / A : 2025-07 OpenAI가 지분 아님, 제휴 없음이라고 반박, 리투아니아 중앙은행이 구조 해명 요청(CNBC 보도 인용) [F-1327](https://www.nbcsandiego.com/news/business/money-report/robinhood-stock-tokens-face-scrutiny-in-the-european-union-after-openai-warning/3862953/). 이후 비상장 수요는 NYSE 상장 펀드 RVI로 제공 [F-1386](https://cdn.robinhood.com/app_assets/rhv/updates/rvi_annual_report_2026.pdf)
- Q : 주식 토큰은 얼마나 큰가? / A : 2026-09-30 주식 토큰 의무 1.85억 달러, 총 플랫폼 자산의 약 0.05%(회사 공시) [F-1279](https://investors.robinhood.com/node/16931/html). 지갑판 발행 잔액 1.49억 달러로 6위(rwa.xyz, 제3자 집계) [F-1025](https://app.rwa.xyz/stocks)
- Q : 숫자의 출처 등급은? / A : 매출, 고객, 거래 규모는 회사 실적 발표 [F-1278](https://investors.robinhood.com/news-releases/news-release-details/robinhood-reports-third-quarter-2026-results). 120개국은 회사 발표 [F-0637](https://investors.robinhood.com/news-releases/news-release-details/robinhood-reports-second-quarter-2026-results). EU 인가는 로펌 ECOVIS 블로그, 프랑스 AMF 등록부로 1차 확인 [F-0215](https://www.amf-france.org/sites/institutionnel/files/pdf/76239/en/Robinhood_Europe_UAB.pdf?1770576252)
- Q : Binance와 무엇이 다른가? / A : Robinhood는 주식 앱이 가상자산과 파생을 뒤에 붙임, 매출 최대는 옵션 3.99억 달러 [F-1276](https://investors.robinhood.com/news-releases/news-release-details/robinhood-reports-third-quarter-2026-results). Binance는 2017 가상자산 거래소가 2026-06에 미국 주식을 붙임 [F-0678](https://www.binance.com/en/about) [F-1198](https://www.aap.com.au/aapreleases/cision20260601ae72536/)
- Q : 캐나다 고객은 어떻게 세나? / A : WonderFi 고객을 2026-06부터 펀디드 고객 집계에 포함 [F-0220](https://finviz.com/news/409270/robinhood-reports-third-quarter-2026-results), 캐나다 가상자산은 WonderFi 자회사 CCML이 제공 [F-0614](https://investors.robinhood.com/node/16931/html)
