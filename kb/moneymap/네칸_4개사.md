# 4개사 네 칸 정리 (자산, 고객, 시장, 거래 시설) 2026-11-22

읽는 법: 칸마다 "→"는 시간 순서. 한 줄은 (판단)

## Kraken
- **자산(무엇을 파나):** 코인 → 선물(2019, 영국 선물 거래소 인수) → 미국 주식(2025, 직접) → 주식 토큰(발행사 인수)
- **고객(누구에게):** 유럽 개인 → 해외 거래소를 사서 북미, 호주 손님 → 미국 선물 앱 손님 200만(NinjaTrader 인수)
- **시장(어디서):** 유럽에서 시작 → 미국은 2025 규제가 풀리자 파생 인가를 사서 들어감
- **거래 시설(어디까지 직접 하나):** 체결만 하다가 → 청산까지(2026 Bitnomial 인수) → 남의 앱에도 빌려줌
- **한 줄:** 인가 하나 따는 데 몇 년 걸리면 산다. 그리고 산 것을 남에게도 판다.

## Coinbase
- **자산:** 코인 → 기관 보관(2018, 직접) → USDC(2018, Circle과 함께) → 선물(2022 거래소 인수, 2023 중개 직접) → 옵션(2025 Deribit 인수) → 예측시장(2025-12, Kalshi로) → 미국 주식(2025-12) → 주식 토큰(2026-08, 미국 밖)
- **고객:** 미국 개인 → 기관(2018 보관, 2020 기관 중개 인수) → ETF 운용사(2024, 미국 가상자산 ETF 자산 80% 넘게 보관) → 미국 밖 기관(2023 버뮤다, 2025 Deribit)
- **시장:** 미국 먼저, 주마다 인가를 직접(2015~2017) → 미국 밖도 대부분 직접(버뮤다, 싱가포르 2023, EU 2025) → 옵션 시장만 삼(Deribit). 매출의 84%가 미국(2025)
- **거래 시설:** 거래소와 보관은 처음부터 직접 → 미국 선물 거래소는 삼(FairX) → 청산소는 직접(2026-09) → 예측시장은 남의 거래소로 열고 자기 청산소를 준비
- **한 줄:** 미국 인가를 먼저, 직접 받아 믿음을 쌓았다. 기다릴 수 없는 시장(옵션)만 샀다.

## Robinhood
- **자산:** 미국 주식(2015 수수료 0) → 옵션(2017 계약 수수료도 0) → 코인(2018) → 신용 매수, 현금 이자(Gold 2016~) → 예측시장(2024-10) → 신용카드(2023 X1 인수), 은행, 자문 → 주식 토큰(2025-06, 미국 밖)
- **고객:** 미국 젊은 첫 투자자(중위 31세, 절반 넘게 첫 증권 계좌) → 같은 손님에게 상품을 계속 얹음 → 기관(Bitstamp 기관 5,000곳 넘게), 자문사(TradePMR 350곳)
- **시장:** 미국 → 영국(2019 인가, 2024 출시), EU(2025) 직접 → 캐나다(WonderFi), 해외 코인(Bitstamp)은 인수 → 싱가포르, 두바이(2026) 직접
- **거래 시설:** 체결은 남(도매업자)에게 보내고 대가를 받음 → 청산은 직접(2018) → 코인 거래소(Bitstamp 2025), 예측시장 거래소와 청산소(MIAXdx 2026)를 사서 체결 쪽으로 올라감
- **한 줄:** 손님을 먼저 모으고 같은 손님에게 상품을 계속 얹었다. 상품이 커지면 체결하는 곳까지 사서 몫을 가져간다.

## Binance
- **자산:** 코인끼리 거래(2017) → 선물(2019-09, JEX 인수로 11일 만에) → 주식 가격 선물(2026-01) → 미국 주식(2026-06, Alpaca에 맡김) → 자체 주식 토큰 bStocks(2026-06) → 미국 주식 옵션(2026-09)
- **고객:** 전 세계 개인(이메일만으로 가입, 2021-08까지) → 큰손(VIP 등급으로 묶음) → 등록 이용자 3억 명 넘게(2025) → 목표 30억 명
- **시장:** 본사 없이 전 세계 → 2021 각국 제재 → 새 제도 나라는 직접 등록(2022 바레인, 두바이, 프랑스 등), 당국과 꼬인 나라는 인수(일본 2022, 한국 2023) → 2025-12 아부다비 인가 3종 → EU는 인가 없음(2026-06 신청 철회), 미국은 별도 법인만
- **거래 시설:** 체결, 청산, 보관을 처음부터 자기가 함(감독 없이) → 2026-01부터 아부다비 거래소, 청산과 예탁, 브로커 인가로 같은 일을 감독 아래서 함 → 미국 주식 체결과 보관만 남(Alpaca)
- **한 줄:** 인가 없이 먼저 크고, 나중에 인가를 모았다. 같은 계정에 상품을 얹어 손님을 붙잡는다.

## 네 회사 한 줄 나란히
| 회사 | 한 줄 |
|---|---|
| Kraken | 몇 년 걸릴 인가는 산다. 산 것을 남에게도 판다 |
| Coinbase | 미국 인가를 먼저, 직접. 기다릴 수 없는 시장만 산다 |
| Robinhood | 손님을 먼저 모으고 상품을 얹는다. 커지면 체결하는 곳까지 산다 |
| Binance | 인가 없이 먼저 크고 나중에 모은다. 같은 계정에 얹어 붙잡는다 |
