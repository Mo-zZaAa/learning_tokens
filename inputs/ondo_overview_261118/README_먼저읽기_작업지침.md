# Ondo 개요 탭 작업 지침

## 할 일
- Ondo 회사 페이지에 **"개요" 탭**을 맨 앞에 새로 만들기. 이미 개요 탭이나 같은 성격의 요약 칸이 있으면 이 내용으로 **덮어쓰기**
- 다른 탭과 DB 행 내용은 건드리지 않기. 단, 새 출처 N01~N21은 사이트 출처 목록에 추가

## 카드 형식
- reference/카드형식_ODX.png와 같은 형식. 사이트에 ODX 카드 컴포넌트가 있으면 **같은 컴포넌트와 태그 스타일을 재사용**
- 줄(row) 순서: 무엇을 하나 → KDX가 볼 이유 → 사업 영역 → 숫자 → 확장 경로 → 배울 점 → 한계, 유의
- 왼쪽은 줄 이름(남색 굵게), "한계, 유의"만 빨간색
- `strong: true` 항목은 남색 굵게(ODX 카드 "배울 점"의 굵은 파란 줄과 같음)
- `numbered: true` 줄(사업 영역)은 번호 목록
- 확장 경로는 ODX처럼 "상품 확장 / 고객 확장 / 시장 확장 / 법인과 인가 / 왜" 소제목 격자. 시장 확장은 (해외자산), (해외고객) 두 줄

## 접기
- 큰 불렛만 처음에 보이고, `kids`나 `table`이 있는 항목은 아래에 **"세부 N" 접기 버튼**(기본 접힘)
- `flow`가 있는 항목은 **"그림: …" 접기 버튼**(기본 접힘)을 따로 둠. 상품 이해용이라 상품 불렛 바로 아래에 둘 것
- 예외: "Ondo가 돈을 버는 시점과 돈이 쌓이는 곳"(`note: true`, flow=revenue)은 표를 접지 않고 바로 보이게
- 세부 안의 들여쓴 하위 항목은 펼친 상태로 함께 보이면 됨(이중 접기 불필요)

## 그림(flows)
- flows의 각 단계(stage)를 상자와 화살표로 그리기. preview html의 `.flow` 구현을 그대로 옮겨도 됨
- 상자 종류: `ondo` 보라(Ondo 그룹 법인과 Ondo 몫), `ext` 청록(외부 회사), `inv` 회색(투자자), `none` 점선(관여 없음), `ondo_dash` 보라 점선(면제 중인 Ondo 몫)
- 단계 오른쪽 위 배지: `earn` 보라(Ondo가 버는 단계), `zero` 점선(0이거나 공시 없음)
- 화살표: `r` →, `l` ←, `""` 화살표 없음
- reference PNG와 JSON 글이 다르면 **JSON이 맞음**(예: PNG 표 아래 "Ondo 몫 연 약 1,062만 달러"는 지금 확인되지 않아 뺐음)

## 태그
- `on-####`: 사이트 DB 행 번호. 그 행의 출처로 연결(기존 방식)
- `N##`: 새 출처. sources_new.csv를 출처 목록에 넣고 연결
- `해석`: 판단(보라 계열), `추정`: 공개 숫자로 직접 계산(주황 계열)

## 글 규칙
- 문구는 고치지 말 것. 줄바꿈 위치만 화면에 맞게
- 대시(—), 가운뎃점(·), "제공" 쓰지 않음. 문장은 명사형 종결

## 확인
