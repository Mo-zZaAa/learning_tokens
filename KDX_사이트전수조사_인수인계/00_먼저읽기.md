# 먼저 읽기: 공식 사이트 전수 조사 인수인계

기준일 2026-11-16. KDX 해외 사례 리서치(Kraken, Robinhood, Binance, Dinari, Ondo, 미국 ATS)에서 공식 사이트를 빠짐없이 수집하기 위한 스킬, 스크립트, 그리고 이미 해둔 작업을 넘긴다.

## 1. 한 줄 요약

- 스킬과 스크립트는 시험이 끝났다. Kraken, Dinari, Ondo 세 사이트에서 실제로 돌렸다.
- 해둔 것은 "목록화와 수집"까지다. 내용을 읽고 정리하는 일(notes, wiki, 기업별틀)은 아직 어느 회사도 하지 않았다.
- 같은 일을 다시 하지 않도록 4번과 5번을 먼저 본다.

## 7. 이미 확인된 것

읽고 정리한 내용이 아니라 수집 과정에서 드러난 구조다.

- Kraken 호스트: www, support, pro, blog, docs, status, wallet, id, app, proapp, assets-cms, email.
- Kraken 사이트가 링크한 다른 도메인 가운데 회사 소유 여부를 확인할 곳: payward.com, services.payward.com, xstocks.fi, krak.app, ninjatrader.com, breakoutprop.com, cfbenchmarks.com, reap.global. kraken.com/institutions/embed가 services.payward.com으로 자동 이동하는 것은 확인했다. 소유가 확인되면 `map --domain 새도메인 --seed https://새도메인`으로 같은 작업 폴더에 추가한다.
- Kraken xStocks 첫 화면에서 눌러야 보이는 영역에 이용 가능 지역 제한 문구와 법적 문서 위치(assets.backed.fi/legal-documentation 안내)가 있다. `work/kraken/raw/www.kraken.com/xstocks.md`의 "펼치거나 눌러야 보이던 내용" 절.
- 사이트맵에 없었는데 페이지 안 링크로 찾은 URL: Kraken 578건, Dinari 225건, Ondo 64건.
- Dinari 호스트: dinari.com, docs, app, partners, sbt, usd, assets, status, api-enterprise. 브로커딜러 공시 PDF 7건(dinari.com/bd 아래), USD+ 백서, 감사 보고서 4건을 변환해 두었다. 사이트가 FINRA BrokerCheck와 SIPC를 링크하므로 등록 사실은 그쪽에서 따로 확인한다.
- Ondo 호스트: ondo.finance, docs, app, blog, status. 아직 훑지 않은 후보(usdy, summit, community, ai 등)는 `work/ondo/map_log.md`에 있다.

## 8. 이어서 하는 명령

스크립트 경로를 S, 작업 폴더를 W라고 하면:

```bash
# Kraken: 대기 0이 될 때까지 반복(8분씩). 끝나면 묶음 생성
python S fetch --work W/kraken --minutes 8
python S digest --work W/kraken

# Ondo: 같은 방식
python S fetch --work W/ondo --minutes 8
python S digest --work W/ondo

# 새 회사: map부터
python S map --work W/robinhood --domain robinhood.com --seed https://robinhood.com

# 위키를 쓴 뒤 누락 점검
python S audit --work W/dinari --wiki W/dinari/wiki
```

특정 구역만 먼저 받으려면 `--only 'https://www.kraken.com/press*'`처럼 범위를 준다.

## 9. 한계와 주의

- Kraken map은 스크립트 초기판으로 돌렸다. 그때는 호스트마다 사이트맵 파일을 400개까지만 열었다. www.kraken.com은 종목마다 사이트맵 파일이 하나씩 있어 그 수를 넘기 때문에 stocks 종목별 목록은 일부(448쪽)만 장부에 있다. 같은 틀이라 내용 조사에는 지장이 없다. 전체 종목 수는 사이트 본문이나 다른 출처로 확인한다.
- `inventory.csv`는 Kraken 기준 44MB다. 통째로 열지 말고 필요한 줄만 뽑는다.
- 수집일은 2026-11-16이다. 종목 수, 수수료처럼 바뀌는 값은 수집일 기준으로 적는다.
- raw와 files는 내부 작업용 원문 변환본이다. 밖으로 나가는 산출물에는 요약과 출처 링크만 쓴다.
- 공식 사이트 내용은 회사가 밝힌 내용이다. 인허가와 등록 사실은 감독기관 등록부로 따로 확인한다.
- robots.txt가 막은 경로, 로그인 화면, 내부용 호스트는 수집하지 않았고 앞으로도 하지 않는다.
- 이 스크립트는 Linux에서 시험했다. Windows나 Mac에서 처음 돌릴 때는 `--help`와 작은 범위(`fetch --limit 5`)로 먼저 확인한다.
