# 개요

확인일: 2026-11-16. 모두 사이트 표기이며 제3자 확인 전의 내용이다.

## 이 사이트는 무엇인가
- Base는 Ethereum 위의 오픈소스 optimistic rollup 프로토콜이라고 약관이 설명한다. [출처](https://docs.base.org/terms-of-service)
- 약관의 상대방은 Coinbase Technologies, Inc.이고, 약관이 다루는 서비스는 Coinbase Sequencer, Base Testnet, Basenames, Dashboard이다. [출처](https://docs.base.org/terms-of-service)
- Coinbase의 Base 관련 권한은 비수탁이며 프로토콜 유지보수로 제한된다고 약관이 명시한다. Coinbase Sequencer는 사용자 가상자산을 보관, 통제, 송수신하지 않는다. [출처](https://docs.base.org/terms-of-service)
- Base 쪽 문구는 스스로를 "중립적이고 허가 없는 인프라"로 부르며, 토큰화 주식은 발행하지 않는다고 거듭 밝힌다. [출처](https://base.org/stocks) [출처](https://www.base.org/blog/tokenized-stocks)
- 반면 토큰화 주식은 "Coinbase가 발행"한다고 같은 사이트가 표기한다. 이 표기는 open-questions.md의 충돌 1번이다. [출처](https://base.org/stocks)

- 토큰화 주식의 발행 법인명은 사이트 어디에도 "Coinbase"라고만 적혀 있고 법인명은 없다. [출처](https://base.org/stocks)
