# Onboarding & KYC

Copy pageCopy page

Onboarding and KYC requirements for Ondo Intelligent Portfolios.

Copy pageCopy page

Onboarding and KYC requirements for Ondo Intelligent Portfolio tokens are the same as for Ondo tokenized stocks. See [Onboarding & KYC](https://docs.ondo.finance/ondo-stocks/onboarding-and-kyc) for details on the process and requirements.Note that if you have already onboarded for Ondo Stocks, no additional onboarding is required to access Ondo Intelligent Portfolios.
