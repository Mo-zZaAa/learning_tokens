# Payward 宣布收购 Reap，扩展 B2B 全球支付基础设施本

本次收购将解锁全球受监管的发卡及稳定币支付基础设施

Payward 今日宣布，已与 Reap Technologies Holdings Limited（“Reap”）签署最终收购协议。Reap 是领先的稳定币原生发卡与支付基础设施公司，专注于推动全球资金流动。本次交易总对价最高可达 6 亿美元，将以现金及 Payward 股权组合支付；本次交易对 Payward 的股权估值为 200 亿美元。

此次收购将进一步扩展 Payward Services——公司旗下 B2B 基础设施平台——的服务能力，新增全球受监管的发卡与稳定币支付基础设施。

Payward Services 为合作伙伴提供单一整合入口，协助其构建全天候运行的金融产品，涵盖加密货币交易、资产托管、代币化资产、法币出入金及衍生品等基础能力。

通过整合 Reap，平台服务将进一步延伸至全球卡片与支付领域。合作伙伴将可在现有能力基础上，直接整合发卡、跨境支付及稳定币资金管理服务，而无需对接多家供应商或管理分散式基础设施。

Reap 已打造一套连接传统金融系统与数字资产的发卡与跨境支付技术架构，协助企业以更高效率、更高透明度及更快速度进行全球资金流转。

其 API 驱动的平台整合卡组织网络、传统金融支付轨道及稳定币原生结算能力，支持企业卡、跨境付款及稳定币资金管理等应用场景。

此次收购正值全球稳定币采用快速增长之际，越来越多企业开始将稳定币应用于支付、资金管理及跨境结算。

**Payward 联合首席执行官 Arjun Sethi 表示：**

*“金融正朝着一个方向演进：全天候市场、可编程货币，以及自主执行。稳定币正在成为新的结算底层，而 AI agents 则是新一代市场参与者。我们已经在自身平台上看到这一转折点：Krak 上线首日即覆盖 110 个国家；xStocks 在推出第一年累计交易量突破 290 亿美元；目前已有 1,900 家 B2B 合作伙伴运行在 Payward 的共享基础设施之上。”*

*“Reap 正是下一代金融体系所需要的支付层：通过单一 API 串联卡组织网络、银行基础设施与区块链，并以稳定币完成结算。支撑这一新金融世界的基础设施，从第一天开始就必须具备开放性、合规性与全球规模化运营能力。下一代金融产品，不再是被拼装出来，而是被直接部署。”*

**Reap 联合创始人兼首席执行官 Daren Guo 表示：**

*“稳定币已经成为当前卡片支付领域最重要的实体应用场景之一，Reap 很荣幸能够走在这股趋势前沿。全球稳定币与加密货币卡市场规模目前已超过每年 180 亿美元。2025 年，Reap 的营收与交易量均接近翻倍增长，并持续将牌照版图由亚洲拓展至南美洲。”*

*“下一阶段，我们将把稳定币卡与支付能力进一步连接至完整的加密原生金融服务体系，协助客户扩大业务规模、拓展监管覆盖范围，并强化市场触达能力。加入 Payward，是加速未来金融发展的自然延伸，也让我们能够在 Web3、Agentic Commerce 等新兴领域打造具市场颠覆性的产品与服务。”*

此次收购也将形成双方互补的全球监管版图。Reap 现有牌照将加速 Payward 在亚太及美洲市场的拓展，而 Payward 在欧盟及美国既有的监管布局，也将协助 Reap 进一步进入欧洲与美国市场。

双方结合后，将共同推动稳定币支付基础设施进一步拓展至中东与北非（MENA）及拉丁美洲等高增长市场。

未来，Reap 的发卡与跨境支付能力将向 Payward Services 合作伙伴全面开放，并结合 Payward 全球流动性、托管及结算基础设施。

交易完成后，Reap 将继续以独立品牌形式在 Payward 生态体系内运营，保留现有品牌、管理团队及市场策略，同时受益于 Payward 的全球基础设施与监管资源支持。

本次交易仍须满足惯常交割条件并取得相关监管机构批准，预计将于 2026 年下半年完成交割。
