# Cost minimum for trading

Last updated: March 31, 2025

Currency availability

Some currencies listed below are not available in [specific countries](/articles/360001368823#h_01F78YK76YHY56DWTEQS2RPAEV).

The Cost minimum order size goes by quote currency. The quote currency is the right or the second currency in a currency pair. For example, in the currency pair BTC/USD, USD is the quote currency.

If an order does not satisfy the cost minimum, it will be canceled and you will see the error, *Cost minimum not met*.

For the minimum order size by base currency see: [Minimum order size (volume) for trading](/articles/205893708-Minimum-order-size-volume-for-trading)

| Quote currency | Cost minimum |
| --- | --- |
| **Cash** |  |
| Australian Dollar | 1 AUD |
| Canadian Dollar | 1 CAD |
| Swiss Franc | 0.5 CHF |
| Euro | 0.45 EUR |
| Pound Sterling | 0.43 GBP |
| Japanese Yen | 50 JPY |
| US Dollar | 0.5 USD |
| **Cryptocurrencies** |  |
| Bitcoin | 0.00002 BTC |
| Dai | 0.5 DAI |
| Ethereum | 0.0002 ETH |
| USD Coin | 0.5 USDC |
| Tether | 0.5 USDT |
