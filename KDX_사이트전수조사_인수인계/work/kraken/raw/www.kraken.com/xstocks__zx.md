## What is tokenized Zillow Group (Zx)?

Tokenized Zillow Group (Zx) is a tokenized stock—a type of blockchain-based asset that represents Zillow Group, Inc. Class C Capital Stock shares. Each Zx digital token is backed 1-1 by real Zillow Group, Inc. Class C Capital Stock shares, held by a third-party custodian.

Trading xStocks like Zx provides indirect exposure to publicly-traded company shares, but it does not constitute ownership of the underlying Zillow Group, Inc. Class C Capital Stock stock. As such, holding tokenized equities does not convey any shareholder rights.
