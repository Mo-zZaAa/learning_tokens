# Sandbox Faucet

post

https://api-enterprise.sbt.dinari.com/api/v2/accounts/{account\_id}/faucet

Mints 1,000 mockUSD sandbox payment tokens to the `Wallet` connected to the `Account`.

This feature is only supported in sandbox mode.

Path Params

account\_id

uuid

required

Body Params

Input parameters for minting sandbox payment tokens.

chain\_id

string

enum

CAIP-2 chain ID of blockchain in which to mint the sandbox payment tokens. If none specified, defaults to eip155:421614. If the `Account` is linked to a Dinari-managed `Wallet`, only eip155:42161 is allowed.

eip155:421614eip155:11155111eip155:84532eip155:168587773eip155:98867null

Allowed:

post

https://api-enterprise.sbt.dinari.com/api/v2/accounts/{account\_id}/token\_transfers

Creates a `TokenTransfer` from this `Account`.

A `TokenTransfer` represents a transfer of tokens through the Dinari platform from one `Account` to another.  
As such, only `Account`s that are connected to Dinari-managed `Wallet`s can initiate `TokenTransfer`s.
