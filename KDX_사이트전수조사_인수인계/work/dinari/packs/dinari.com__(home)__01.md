### Build with the dShares™ API.

Build custom trading experiences, automate order flow, or plug dShares™ into your product with the Dinari API.

[explore integration](https://docs.dinari.com/)

```
import Dinari from '@dinari/api-sdk';

const client = new Dinari({
  apiKeyID: process.env['DINARI_API_KEY_ID'],
  apiSecretKey: process.env['DINARI_API_SECRET_KEY'],
  environment: 'production',
});

async function main() {
  const entity = await client.v2.entities.create({
    name: 'John Doe LLC',
  });

  console.log(entity);
}

main();
```
