# Create Withdrawal Request

post

https://api-enterprise.sbt.dinari.com/api/v2/accounts/{account\_id}/withdrawal\_requests

Request to withdraw USD+ payment tokens from a managed `Account` and send the equivalent amount of USDC to the specified recipient `Account`.

The recipient `Account` must belong to the same `Entity` as the managed `Account`.

account\_id

uuid

required

Body Params

Input for withdrawing USD+ payment tokens from an `Account` connected to a Dinari-managed `Wallet`.

recipient\_account\_id

uuid

required

ID of the `Account` that will receive payment tokens from the `Withdrawal`.

payment\_token\_quantity

number

required

≥ 0

Amount of USD+ payment tokens to be withdrawn. Must be greater than 0 and have at most 6 decimal places.
