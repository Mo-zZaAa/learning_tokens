# 수수료와 가격
확인일 2026-11-16. 회사가 밝힌 내용.

- 파트너와 최종 사용자에게 거래 수수료를 받지 않는다. 부과 항목: API 접근료 월 2,000달러부터(샌드박스 무료), 네트워크 수수료 표준 주문당 0.20달러, USDT 환전 수수료 오라클 가격 + 3bp, OTC 주문 수수료(최소 25,000달러, 스프레드 통상 10bp까지). 2026-11-10 갱신 표기. [출처](https://docs.dinari.com/docs/fees)
- 파트너는 `fee` 파라미터로 고객 수수료를 정할 수 있다(기본 0.20달러). [출처](https://docs.dinari.com/docs/fees)
- FAQ는 발행 수수료를 이더리움 1달러 + 0.25~0.50%, L2 0.20달러 + 0.25~0.50%로 적어 fees 페이지와 어긋난다. [출처](https://docs.dinari.com/docs/faqs)
- 미국 브로커리지는 거래별 수수료(명목금액에 따라 변동)를 받고 규제, 거래소, 청산 수수료는 부담한다. [출처](https://dinari.com/us/disclosures)
- 실시간 NBBO 시세 조회는 요청당 0.0075달러(미국 고객, 정규장). [출처](https://docs.dinari.com/docs/us)
- 제3자 결제 파트너가 환전 스프레드, 발행과 환매 수수료, 네트워크 비용을 부과할 수 있다. [출처](https://dinari.com/us/disclosures)
