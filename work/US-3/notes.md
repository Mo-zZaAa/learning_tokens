# US-3 노트 (2026-11-16 11:58Z)
- law.cornell.edu(LII 게재 eCFR와 US Code)는 셸 curl로 열려 원문을 sources/US-3/에 텍스트 저장. 조문 17건을 laws.csv에 수록.
- sec.gov는 WebFetch 해석 실패, 셸 403. ecfr.gov API는 짧은 오류 응답. 1차 출처는 LII 게재 eCFR로 대체(검증 상태를 1차 출처 확인으로 표기했으나 게재처는 LII임).
- 못 채운 것: 토큰 상품에 미국인 제외 구조가 쓰이는 사례 원문(SEC 성명, 사업자 투자설명서), Rule 144A 후속 조건 전체, 902(h)(1)(ii)와 904 상세, Reg A 발행 한도 이후 개정 여부. 이 부분은 sec.gov 허용 후.
- 시행일 열은 열람일 기준 현행본으로 적음(조문별 개정일은 원문에서 확인 못 함).
- 범위 밖: kb/에 이미 5개 파일 존재(각 1줄).
- 용어 중 "한국의 대응"은 일반 지식이라 추후 KR 에이전트가 확인 필요.
