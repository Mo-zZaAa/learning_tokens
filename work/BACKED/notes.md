# BACKED notes (기준일 2026-11-16)
- 입력은 사용자 제공 PDF 4개 합본(inputs/manual/B01_backed_base_prospectus_20260727.txt). 쪽 번호는 인쇄 쪽 번호이고 PDF 쪽과 같다(164쪽). 2차 보충서 사실(Payward 계열 제공 법인, Backed Finance AG 모회사, 재정 의존 위험 등)은 work/MANUAL 쪽에 있어 다시 넣지 않았다.
- 인가 보유 주장(JFSC 동의, FMA 승인)은 등록부 미확인이라 검증 상태를 단일 출처로 했다. 상품 내용 사실은 1차 출처 확인.
- 투자설명서는 보유자 권리(배당, 의결권)를 배제하지만 배당 처리는 상품별 Final Terms에 위임하고, 계정관리약정(p.97)은 배당 현금을 발행사 고유계정으로 이전하는 것을 허용한다. 사용자 안내 화면과 비교할 때 이 둘이 충돌할 수 있어 별도 확인 필요.
- 범위 밖 발견: 투자설명서 p.8 스위스(전문투자자만), 영국(적격투자자 등) 구분. 한국 투자자 대상 판매는 이 문서로 판단 불가.
- 투자설명서가 가리키는 Final Terms와 승인 참가자 목록은 www.backedassets.fi에 있음. 셸과 WebFetch로 열지 않았다(범위 밖, 15분 상한).
- 기존 PROD 줄의 Alpaca Securities LLC 소재지(뉴욕)와 투자설명서(노스캐롤라이나 Wilmington, p.70)가 다르다. 어느 쪽이 맞는지 판정하지 않고 prod_fix.md에 불일치로 적었다.
