## 2. 패턴
- 주로 쓴 방법 : 새 자산과 새 고객층(가상자산, 관리계좌, 비상장 펀드, 지갑판)은 직접 등록, 남이 이미 가진 시설과 고객(미국 밖 거래소, 선물 거래소와 청산소, RIA 수탁, 캐나다 거래소)은 인수. 인수 4건(TradePMR, Bitstamp, MIAXdx, WonderFi)이 2025-02~2026-06에 몰림 [F-0603][F-0605][F-0610][F-0608]
- 앞의 확장이 다음을 연 경로(근거 있음)
  - 선물 중개 법인(FCM) → 2025-03 예측시장 허브(발표문이 Robinhood Derivatives를 제공 주체로 적음, 계약은 Kalshi 경유) → 예측시장이 매출 기준 가장 빨리 크는 상품이 되어 거래소와 청산소를 직접 보유하려고 2026-01 MIAXdx 인수(회사 뉴스룸) [F-1155][F-1156][F-1383][F-0610]
  - 2025-06 Bitstamp 인수 → 같은 달 EU 무기한선물 주문을 Bitstamp 거래소로 연결, 2026-07 지갑판 1차 청약 창구를 Bitstamp Global 한 곳으로 [F-0224][F-0871]
  - 2023 리투아니아 VASP 등록 → 2025-06 MiCA, MiFID 인가 → EU 주식 토큰 → 2026-07 자체 체인으로 이전 [F-0212][F-0214][F-0221][F-0225]
- 다른 5곳과의 차이 : 6곳 중 유일한 주식 앱 출신으로, 가상자산과 파생을 나중에 붙임(Kraken, Coinbase, Binance는 가상자산 거래소 출신으로 반대 방향, Dinari와 Ondo는 고객 앱 없이 발행해 파트너에 공급). 그 결과 2026 Q3 거래 기반 매출에서 이벤트 계약(1.73억 달러)이 주식(1.21억)과 암호화폐(1.20억)를 넘어섬 [F-0612][F-1276]
- 해외(나라별)
  - EU(EEA) : 직접 인가(리투아니아 MiCA, MiFID) + 인수(Bitstamp, Bitstamp Europe은 룩셈부르크 MiCA 인가) [F-0213][F-0214][F-0253]
  - 영국 : 직접(RHUK가 중개, 가상자산, 선물) [F-0613][F-0620]
  - 캐나다 : 인수(WonderFi 자회사 CCML) [F-0614]
  - 싱가포르 : 직접 인가(MAS), 미출시 [F-0617]
  - 두바이 : 직접 인가(DFSA), 2027 출시 예정 [F-1284]
  - 그 밖 120개국 이상 : 무인가 판매(저지 비규제 발행사 RHJ, 미국 증권법 미등록, 케이맨 자회사의 비수탁 지갑). 인가를 가진 캐나다, 영국은 지갑판 제한 지역 [F-0637][F-0854][F-0636][F-0615][F-0880]
  - 현지 파트너가 고객을 맡는 나라 : 확인된 곳 없음

## 3. 축 후보

### 후보 A(추천)
- 축 문장 : 주식 앱 고객에게 예측시장을 파트너(Kalshi)로 먼저 열고 거래소 인수(MIAXdx)로 직접 운영으로 옮겨, 이벤트 계약 매출(2026 Q3 1.73억 달러)이 주식과 암호화폐 매출을 넘는 종합 거래 앱이 됨
- 받치는 사실
  - F-1156 : 2025-03 예측시장 허브를 앱에 출시, 계약은 CFTC 규제 거래소 Kalshi 경유 : https://robinhood.com/us/en/newsroom/robinhood-prediction-markets-hub/
  - F-1383 : 예측시장이 매출 기준 가장 빨리 크는 상품이 되어 거래소와 청산소를 직접 보유하기로 함(합작 이유) : https://robinhood.com/us/en/newsroom/robinhood-prediction-markets-joint-venture
  - F-1276 : 2026 Q3 거래 기반 매출 8.67억 달러 중 옵션 3.99억, 이벤트 계약 1.73억, 주식 1.21억, 암호화폐 1.20억 달러 : https://investors.robinhood.com/news-releases/news-release-details/robinhood-reports-third-quarter-2026-results
- 가설 판단 : 다 한다. 같은 개인 고객에게 주식, 옵션, 가상자산, 선물, 예측시장, 자문, 비상장 펀드까지 붙였고 회사 소개도 중개, 암호화폐, 자문, 디지털 은행, 비상장 접근을 함께 듦 [F-0612][F-1283]
- 자기 점검
  - 다른 회사 이름으로 바꿔도 맞나 : 아님. Coinbase도 Kalshi 경유로 예측시장을 연 뒤 자체 계약으로 옮겼으나, 주식 앱 고객 기반과 이벤트 계약 매출이 주식 매출을 넘은 점은 Robinhood만 해당
  - 연혁 요약인가 : 아님. 왜(가장 빨리 크는 상품)와 무엇이 다음을 열었나(Kalshi 경유로 수요 확인 → 인수)가 들어 있음
  - 금지 요소 : 없음(합작 지분 구조, 인수 금액, 상품 법적 구조는 넣지 않음)

### 후보 B
- 축 문장 : 미국 밖은 가상자산 거래소 인수(Bitstamp, WonderFi)와 나라별 직접 인가(EU, 영국, 싱가포르, 두바이)로 들어가, 회사 암호화폐 거래액의 58%(2026 Q3 500억 달러 중 290억)가 인수한 Bitstamp에서 나오는 다국적 중개사가 됨
- 받치는 사실
  - F-1197 : Bitstamp 인수 이유는 미국 밖 확장과 첫 기관 사업 확보(2024-06-06 발표, 2025-06-02 종결) : https://www.robinhood.com/us/en/newsroom/robinhood-to-acquire-bitstamp
  - F-0237 : 2026 Q3 암호화폐 명목 거래액 500억 달러 중 앱 210억, Bitstamp 290억 달러 : https://finviz.com/news/409270/robinhood-reports-third-quarter-2026-results
  - F-0213 : 2025-06 리투아니아 MiCA 가상자산서비스 인가, EEA 패스포트 가능 : https://www.ecovis.com/lithuania/blog/2025/06/15/us-broker-robinhood-obtains-lithuanian-a-category-mifid-brokerage-and-mica-license-for-crypto-services-in-the-european-union/
- 가설 판단 : 다 한다. 나라마다 인가든 인수든 가리지 않고 진입했고 인가만 받고 아직 열지 않은 곳(싱가포르, 두바이)도 있음 [F-0617][F-1284]
- 자기 점검
  - 다른 회사 이름으로 바꿔도 맞나 : 일부 겹침. Coinbase도 미국 밖 기관 고객을 Deribit 인수로 얻음. 290억 달러, 58% 숫자와 인가 4곳 나열로 구분됨
  - 연혁 요약인가 : 아님. 왜(미국 밖 확장, 기관 사업)는 있으나, 290억 달러에는 인수 전부터 있던 Bitstamp 고객이 섞여 인수 뒤 새로 키운 몫과 구분되지 않음
  - 금지 요소 : 없음(인수 금액은 넣지 않음)
