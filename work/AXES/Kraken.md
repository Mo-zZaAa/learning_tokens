# Kraken(Payward) 축

- 범위 : Kraken은 거래소와 앱 이름, 숫자와 인수 주체는 모회사 Payward, Inc. 단위 [F-0176][F-0180]

## 2. 패턴

- 주로 쓴 방법 : 인수. 2019 이후 인수 8건(Crypto Facilities, 키프로스 투자회사, NinjaTrader, Small Exchange, Backed, Bitnomial, Reap, Saldo 계약), 공개 금액만 최소 27.5억 달러(토큰포스트 보도). 직접은 주로 나라별 인가(와이오밍, 버뮤다, 아일랜드, SEC 등록) [F-1355][F-1337][F-1416][F-1371][F-0242]
  - 인수 이유(회사 쪽 말) : 미국 선물 중개업체를 처음부터 세우면 기술과 규제 승인에 비용과 시간이 많이 듦(Sethi, 코인데스크 보도), 사지 못하는 신뢰와 입지는 Nasdaq, LSE 같은 기관과 제휴 [F-1346][F-1349]
- 앞의 확장이 다음을 가능하게 한 것
  - 버뮤다 직접 인가(2024-08) → xStocks 미국 밖 판매(2025-04 AP 계약) : 저지 감독청이 발행사에 AP를 규제 금융회사로 한정하라고 요구해 인가 법인이 있어야 판매 가능 [F-0990][F-0919]
  - 키프로스 투자회사 인수(2025-02) → EU 개인에 xStocks 판매(2026-05) : 주식 토큰은 EU에서 가상자산이 아니라 증권이라 MiCA 인가로는 못 팔고 증권 판매 인가가 따로 필요 [F-0148][F-1370][F-0920]
  - NinjaTrader(FCM) + Bitnomial(DCM, DCO) → 개별주식 무기한선물 서류(2026-09) : Bitnomial 거래소가 시장과 청산, NinjaTrader Clearing이 고객 계좌 [F-1189]
  - Reap 인수 → 결제 지역 확대 : Reap 기존 인가로 아시아태평양과 미주, Payward의 EU와 미국 인가로 Reap의 유럽과 미국 진출(회사 발표) [F-1256]
  - xStocks 판매(2025-06) → Backed 인수(2025-12) : 회사 이유는 발행, 거래, 결제를 한 틀로 묶는 것. 판매 성과가 인수를 가능하게 했다는 근거는 없음(순서만 사실) [F-1043]
  - 해석 : 인수한 인가와 발행사를 같은 매칭 엔진, 위험 엔진, 정산 위에 올리고(회사 문장), 그 인프라를 다시 Payward Services로 외부에 팖 [F-1258][F-1350]
- 다른 5곳과 다른 점
  - Coinbase는 미국 중개(FCM)와 청산소(DCO)를 직접 등록하고 주식 토큰을 직접 발행, Kraken은 미국 파생 인가 셋과 발행사를 모두 인수 [F-1228][F-1123][F-1118][F-0939]
  - Robinhood는 주식 앱에서 출발해 가상자산 거래소(Bitstamp)를 인수, Kraken은 가상자산 거래소에서 출발해 주식 중개와 선물 중개를 붙임 [F-0605][F-1117]
  - Binance는 아부다비 한 곳에 인가 3종을 모음, Kraken은 버뮤다, 아일랜드, 키프로스로 판매 법인을 나눔 [F-0064][F-0919][F-1371]
  - Dinari, Ondo는 주식 토큰이 본업, Kraken은 주식 토큰이 본업의 일부(총플랫폼마진에서 xStocks 몫 미공개) [F-1246]
  - 이번 6곳 본문 중 예금과 대출을 하는 은행 계층(SPDI, 아일랜드 EMI, 연준 제한목적 마스터 계정, Saldo Bank 계약)을 쌓는 곳은 Kraken [F-1254][F-1194]
- 해외(나라별)
  - 미국 : 직접 인가(SEC 브로커딜러, 와이오밍 SPDI) + 인수(선물 인가 셋). 주식 토큰은 미국 증권법 미등록이라 미국인에게 팔지 않음 [F-0242][F-1118][F-0971]
  - 버뮤다 법인으로 미국 밖 여러 나라 : 직접 인가 법인 하나가 판매, 판매국 증권 규제기관에는 등록하지 않음(Payward 발표) [F-0154][F-1369]
  - EU(EEA) : 직접 인가(아일랜드 MiCA) + 인수 인가(키프로스 MiFID), 상품은 리히텐슈타인 FMA 승인 투자설명서로 29개국 공모 [F-1371][F-0920][F-0918][F-0976]
  - 스위스 : 전문투자자에게만 [F-0973]
  - 미국, 캐나다, 영국, 호주 : 주식 토큰 판매 안 함 [F-0393]
  - 홍콩, 영국, EU 상장주 : 현지 파트너(GTN이 집행, 수탁, 현지 인가 뒤 자기 기관 고객 응대) [F-1084][F-0174]
  - 독일 : 파트너 거래장(독일거래소 360X) [F-0175]
  - 아시아태평양 결제 : 인수한 Reap의 인가 [F-1256]
  - 한국 : 한국 상장자산 토큰화는 GTN 확장 순서의 뒤쪽, 기한 미공개 [F-0170][F-0171]
