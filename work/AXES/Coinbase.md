## 2. 패턴

- 주로 쓴 방법 : 직접 인가와 직접 출시. 인가는 BitLicense, 신탁, 버뮤다, FCM, MiCA, FSRA, DCO가 직접. 인수는 직접 만들기 어려운 빈 곳(선물 거래소 FairX, 옵션과 해외 기관 Deribit, 증권사 Keystone, 기관 거래 Tagomi)에만 [F-1412][F-1416][F-1228][F-0254][F-0095][F-1123][F-1122][F-1378][F-1120][F-1377]
  - 제휴는 상품 공급처로 : USDC(Circle), 예측시장 초기(Kalshi), 주식 토큰 보관(Alpaca) [F-0790][F-1376][F-0081]
- 앞의 확장이 다음을 가능하게 한 것
  - 예측시장 : Kalshi 연결로 먼저 열고(2025-12) CFTC 승인 뒤 자체 계약 상장으로 바꿈 [F-1376][F-0907]
  - Deribit 인수(2025-08) → INTX와 통합(2026-10) : 미국과 미국 밖 고객을 잇는 단일 규제 거래소(회사 공시), Deribit을 미국과 미국 밖 모두에 제공(CEO) [F-0903][F-1062]
  - 기관 보관(2018) → 주식 토큰(2026) : CEO가 크립토 최대 수탁기관이자 가장 신뢰받는 브랜드라 주식 토큰에서 이길 권리가 있다고 말함(회사 주장) [F-1061]
  - USDC → 앱 주식 결제 : 미국 앱 주식과 ETF를 USDC로 결제(Fnnews 보도) [F-0101]
  - 해석 : FairX(DCM, 2022) → FCM 직접 등록(2023) → DCO 직접 등록(2026) 순서로 미국 선물을 그룹 안에서 끝까지 처리. 이 순서를 고른 이유를 밝힌 회사 문장은 없음 [F-1122][F-1228][F-1123]
- 다른 5곳과 다른 점
  - Kraken은 미국 파생 인가 셋을 모두 인수, Coinbase는 거래소만 인수하고 중개와 청산소는 직접 등록 [F-1118][F-1228][F-1123]
  - Robinhood는 예측시장 거래소와 청산소를 합작법인으로 인수(MIAXdx), Coinbase는 Kalshi 연결 뒤 자체 계약으로 옮김 [F-0610][F-0907]
  - Binance는 아부다비에 거래소, 청산, 중개 인가를 모아 글로벌 사업 기반으로 씀, Coinbase는 아부다비를 주식 토큰 발행 전용으로 쓰고 본진은 미국 인가 [F-0064][F-0082]
  - Kraken은 발행사를 인수해 남이 만든 상품을 자기 것으로, Coinbase는 처음부터 직접 발행 [F-0939][F-0777]
  - Dinari, Ondo는 주식 토큰이 본업, Coinbase는 주식 토큰 단독 매출을 공개하지 않을 만큼 작은 사업이고 본업은 거래, 스테이블코인, 보관 [F-0089][F-1260][F-1262]
- 해외(나라별)
  - 미국 : 직접 인가(BitLicense, 신탁, FCM, DCO) + 인수(FairX 거래소, Keystone 증권사). 주식 토큰은 미국 상품 없음, SEC 혁신 면제 뒤 검토 [F-1412][F-1228][F-1123][F-1122][F-1120][F-0898]
  - EU(EEA) : 직접 인가(룩셈부르크 MiCA), 이미 하던 EEA 영업을 MiCA로 이전 [F-0102][F-0254]
  - 영국 : 직접 등록(FCA 등록 가상자산사업자, 회사는 그중 최대라고 밝힘) [F-0102]
  - 버뮤다 : 직접 인가(BMA Class F 법인 2곳) [F-1416]
  - 아부다비 : 직접 인가(FSRA), 주식 토큰 발행 법인 설립 [F-0095][F-0082]
  - 미국 밖 적격 관할 개인(주식 토큰) : 판매국 현지 인가 근거 없음. 발행지 인가(ADGM)와 미국 밖 판매 면제(Regulation S)에 기대어 Base 위 DeFi로 유통, 2차 거래는 KYC 없이 가능, 모든 시장에서 이용 가능하지는 않음 [F-0079][F-0739][F-0757]
  - 미국 밖 파생 고객 : 인수(Deribit) [F-1378][F-0904]
  - 현지 파트너가 고객을 맡는 나라 : 근거 없음
  - 한국 : 정식 영업 없음, 코인원 지분 투자 논의 보도(확정 아님) [F-0114]

## 3. 축 후보

### 후보 1(추천)
- 축 문장 : 직접 인가(선물 중개 2023, 청산소 2026)와 빈 곳만 메우는 인수(선물 거래소 FairX, 옵션 거래소 Deribit)로 현물 거래소에 선물, 옵션을 붙여, 거래대금의 대부분이 파생에서 나오는 회사가 됨(2026 Q3 총 거래대금 1조 2,138억 달러 중 파생 9,859억 달러, 약 81%는 우리 계산)
- 받치는 사실
  - F-1123 : Coinbase Clearing LLC가 2026-09-28 CFTC 청산소(DCO)로 직접 등록(인수 아님) https://www.cftc.gov/IndustryOversight/IndustryFilings/ClearingOrganizations
  - F-1378 : Deribit 인수 약 29억 달러, 이유는 옵션 1위 거래소를 더해 현물, 선물, 무기한, 옵션을 한 플랫폼에와 해외 확장, 2025-08 완료 https://www.coinbase.com/blog/coinbase-to-acquire-deribit-becoming-the-most-comprehensive-global-crypto-derivatives-platform
  - F-1263 : 2026 Q3 총 거래대금 1조 2,138억 달러(현물 1,345억, 파생 9,859억, 스테이블코인 935억) /home/user/learning_tokens/inputs/manual/B03_coinbase_Q3_26_shareholder_letter.pdf
- 가설 판단 : 다 한다. 회사가 2026 우선순위 1로 암호자산, 주식, 예측시장, 원자재, 외환을 한 곳에서 거래(Everything Exchange)를 명시 [F-0899]
  - 수익 쪽 한계 : 예측시장과 파생을 합쳐도 거래수익의 25%, 거래대금 비중보다 작음 [F-1261]
- 자기 점검
  - 다른 회사 이름으로 바꿔도 맞나 : 아님. Kraken은 청산소를 인수, Robinhood는 옵션 거래소 인수 없음, 파생 9,859억 달러는 Coinbase 값. 통과
  - 연혁 요약인가 : 아님. 방식(직접 인가 중심, 빈 곳만 인수)과 그 결과(파생 중심 회사)를 씀. 통과
  - 사고, 소송, 인수 세부, 법적 구조, 기술 설명이 들어갔나 : 인수 금액과 조건, SEC 소송 없음. 통과
