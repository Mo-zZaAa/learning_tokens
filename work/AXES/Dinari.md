# Dinari 확장 방식과 축 후보

● 범위 : 확장과 파트너십 방식만 봄(누구와 어떤 방식으로 붙어 유통을 넓혔나, 결과 숫자는 있으면 적음). 회사 매출, 고객 수는 비공개라 규모는 발행 잔액과 파트너 사례 연구 숫자로만 봄 [F-1027][F-0347]
  - 뜻 : 직접 = 회사가 스스로 출시, 등록, 구축. 파트너 = 다른 회사와 제휴하거나 다른 회사 앱, 거래소를 통해 공급. 인수 = 기존 회사를 사서 확보(Dinari는 해당 없음)

## 2. 패턴
● 주로 쓴 방법 : 인가(명의개서 2022, 증권사 2025)와 발행은 직접, 고객 접점과 기능 보강은 파트너. 표 17건 중 파트너가 들어간 확장 12건, 인수 0건 [F-1237][F-0116][F-0332]
● 앞의 확장이 다음 확장을 가능하게 한 것
  ★ B2B API(2024-02) → 파트너는 증권사 등록 없이 판매, Dinari가 브로커리지, 결제, 수탁, 규정 준수를 맡음 → 급여 플랫폼(Cadana), 국경 간 금융 앱(Meru) 같은 비증권 앱이 판매 창구가 됨 [F-0277][F-0332][F-0335][F-1085][F-1087]
  ★ 명의개서대리인 등록(2022-05)과 증권사 등록(2025-06) → 미국인 판매 불가였던 상태에서 2026-08 미국판 724종 출시, 미국 증권사에 API 제공 [F-0313][F-1237][F-0116][F-1131]
  ★ Flow Traders 제휴(2025-12) → 정규장 밖 호가, 2026-11-16 24시간 세션 9종목 [F-1036][F-0343]
● 다른 5곳과 다른 점 : Kraken, Robinhood, Coinbase, Binance는 인가나 인수로 판매 법인을 갖추고 자기 앱 고객에게 직접 판매하고, Ondo는 대형 가상자산 거래소와 지갑(Bitget, Binance 등)에 공급. Dinari는 증권사 역할을 대신 맡는 API로 소형 핀테크 앱에 공급하며, 파트너별 거래대금은 수십만에서 수백만 달러대 [F-0221][F-0749][F-0202][F-0332][F-0350][F-0351]
● 해외 : 현지 파트너. 미국 밖 발행은 미국 인가 없이 Regulation S로 하고(현지 인가 근거는 회사가 제시하지 않음), 판매 접점은 각국 파트너 앱 [F-0273][F-0313][F-0271][F-0332]
  - 뜻 : Regulation S = 미국 밖에서 미국인 아닌 사람에게 파는 증권은 미국 공모 등록이 필요 없다는 규정 [US-17CFR-230.903-a]

## 3. 축 후보

### 후보 A(추천)
● 축 문장 : 증권사 역할을 대신 맡는 API 공급으로 증권사 등록 없는 급여, 송금, 투자 핀테크 앱을 판매 창구로 붙여, 자기 고객 화면 없이 60개국 이상(회사 주장)에 미국 주식 토큰을 대는 B2B 공급사가 됨(발행 잔액 1,520만 달러, rwa.xyz 집계 11위) [F-0332][F-0281][F-1027]
● 받치는 사실
  ★ F-0332 : 유통 파트너는 단일 API로 증권사 등록 없이 토큰 주식 제공 https://dinari.com/business
  ★ F-0350 : Meru(중남미 국경 간 금융 앱) 고객 거래대금 440만 달러 이상, 고객 4,814명, 44개국(회사 사례 연구, 2026-07-15) https://dinari.com/case-studies/meru
  ★ F-1027 : 발행 잔액 1,520만 달러, 11위, 점유율 0.41%(rwa.xyz 집계, 2026-11-16) https://app.rwa.xyz/stocks
● 가설 판단 : 둘 다 아님. 주식 토큰 B2B 공급 하나에 집중했으나 그 영역에서 1등이 아님(잔액 11위, 1위 Binance의 약 1/90) [F-1027][F-1021]
  - 해석 : 파트너 API는 파트너가 고객을 데려와야 커지는 구조라, 2023-08 가장 먼저 시작하고도 잔액 점유율은 0.37%에서 0.41%로 거의 그대로 [F-0273][TP-004][F-1027]
● 자기 점검
  ★ 다른 회사 이름으로 바꿔도 맞나 : 아님. Ondo는 대형 거래소, 나머지 4곳은 자기 앱 판매 [F-0202][F-0221]
  ★ 연혁 요약인가 : 아님. API가 파트너의 증권사 등록 부담을 없애 비증권 앱이 창구가 된 연결을 담음 [F-0335]
  ★ 사고, 소송, 인수 세부, 법적 구조, 기술 설명 : 없음
  ★ 결론 : 통과

### 후보 B
● 축 문장 : 명의개서대리인과 증권사 자격을 직접 등록해 미국 투자자, 사업자, 미국 증권사를 고객으로 붙여, 미국 밖 전용 발행사에서 미국 53개 주와 영토에 724종을 공급하는 회사가 됨 [F-1237][F-0116][F-0120][F-1131]
● 받치는 사실
  ★ F-1237 : Dinari, Inc/TA 명의개서대리인 등록 신청서 2022-04 접수, 2022-05 SEC 수리 https://www.sec.gov/Archives/edgar/data/1915430/000191543022000003/0001915430-22-000003-index.html
  ★ F-0116 : Dinari Securities 2025-06-20 FINRA 승인, SEC 등록 증권사 https://api.brokercheck.finra.org/search/firm/329672
  ★ F-1131 : 2026-08-04 미국 투자자가 USDC로 724종 거래, 미국 내 증권사에 API 제공(Circle 제휴) https://dinari.com/blog/dinari-launches-724-tokenized-stocks-available-to-u-s-investors-and-businesses
● 가설 판단 : 1등 집중 쪽. 미국 토큰 주식 종목 폭 724종으로 Ondo 미국 보관형(2026-07, IVV, MU 2종)보다 넓으나 미국판 잔액은 비공개라 1등 여부는 확인 못 함 [F-1131][F-1128]
● 자기 점검
  ★ 다른 회사 이름으로 바꿔도 맞나 : 아님. Ondo는 같은 미국 자격을 인수(Oasis Pro)로, Kraken은 증권사를 등록했으나 토큰이 아닌 실물 주식 판매 [F-1216][F-0242][F-0420]
  ★ 연혁 요약인가 : 아님. 두 등록이 미국인 판매 불가 상태를 풀어 미국판 출시로 이어진 연결을 담음 [F-0313][F-1131]
  ★ 사고, 소송, 인수 세부, 법적 구조, 기술 설명 : 없음(토큰의 법적 성격은 넣지 않음)
  ★ 결론 : 통과
