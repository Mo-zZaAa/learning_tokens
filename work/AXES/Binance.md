## 2. 패턴
- 주로 쓴 방법 : 직접. 인수는 한국 고팍스 1건뿐, 파트너는 새 자산을 먼저 들여볼 때(2021 CM-Equity 주식 토큰, 2026-02 Ondo 토큰 상장)와 실물 처리(Alpaca 주식 집행과 보관, 아르헨티나 법정화폐)에 씀 [F-1389][F-1124][F-1125][F-1198][F-0715]
- 앞의 확장이 다음을 연 경로
  - 근거 있음 : 2025-12 ADGM 브로커딜러 인가(Nest Trading) → 2026-06-01 미국 주식 직접 거래 → Teng이 "주식 거래 초기 수요"를 근거로 bStocks를 "다음 단계"라 함 → 2026-06-12 bStocks, 주식과 1:1 전환은 Nest Trading이 맡음 [F-0066][F-1198][F-1068][F-0050]
  - 근거 있음 : 거래소 이용자 기반이 토큰 수요로 이어짐. 초기 bStocks 이용자의 58.5%가 무기한선물이나 직접 주식도 거래 [F-0063]
  - 근거 있음 : bStocks 다음 활용처는 회사 목표(거래에서 헤지, 마진, 위험 관리로)대로 2026-09 담보, 2026-10 주식 무기한선물 [F-1288][F-0062][F-1231]
  - 해석 : 파트너 토큰(2021 CM-Equity, 2026 Ondo) → 자체 발행 순서는 남의 상품으로 수요를 본 뒤 직접 만드는 흐름으로 보이나, 회사가 이 순서의 이유를 밝히지 않음 [F-1124][F-1125][F-1126]
- 다른 5곳과의 차이 : Kraken, Coinbase처럼 가상자산 거래소 출신이지만 미국 선물 거래소와 중개사를 인수해 미국 안을 키운 두 회사(NinjaTrader, FairX, Deribit 등)와 달리, 아부다비 한 관할에서 거래소, 청산소, 중개 인가를 직접 받아 미국을 빼고 키움. Coinbase도 ADGM에서 주식 토큰을 내지만 ADGM 인정기관(거래소, 청산소)은 Binance 계열만 2곳. Robinhood는 나라별 인가와 인수, Dinari와 Ondo는 발행만 하고 판매는 파트너 [F-1418][F-0054]
- 해외(나라별)
  - 아부다비(ADGM) : 직접 인가(거래소, 청산소, 중개), 그룹 규제 거점(Teng 발언) [F-0064][F-0065][F-0066][F-1071]
  - 두바이 : 직접 인가(VARA) [F-0068]
  - 한국 : 인수(고팍스), bStocks 한국 제공 근거 없음 [F-0073][F-0075]
  - 아르헨티나 : 직접 등록(라이선스 아님) + 현지 파트너가 법정화폐 거래 처리 [F-0713][F-0715]
  - 일본 : Binance Japan 법인 있음, 진입 방식은 DB에 없음 [F-0716]
  - 미국 : bStocks 판매 제외(미국과 미국인) [F-0054]
  - 그 밖 100여 개국 : 무인가 판매 쪽. 거래소 직접 접속으로 판매하고 bStocks 공모는 ADGM 안에서만, 허용 지역 이용자에게 2차 시장으로 제공, 허용국 목록과 나라별 현지 인가 근거는 공개 자료에 없음 [F-1201][F-1126][F-0054]

## 3. 축 후보

### 후보 A(추천)
- 축 문장 : 가상자산 거래소 이용자에게 직접 받은 ADGM 인가로 실물 미국 주식 거래를 먼저 열고 그 위에 1:1 전환되는 자체 발행 bStocks를 같은 거래소 상품으로 붙여, 출시 약 4개월 만에 누적 거래 400억 달러가 오가는 주식 겸 가상자산 거래소가 됨
- 받치는 사실
  - F-1198 : 2026-06-01 미국 상장 주식과 ETF 7,000종 이상 거래 개시(Nest Trading 경유, Alpaca가 집행과 보관) : https://www.aap.com.au/aapreleases/cision20260601ae72536/
  - F-0063 : 초기 bStocks 이용자의 58.5%가 무기한선물이나 직접 주식도 거래(기존 거래소 이용자가 주 수요) : https://www.prnewswire.com/news-releases/binances-bstocks-become-the-fastest-tokenized-equity-product-to-surpass-1-billion-in-assets-under-management-302909927.html
  - F-0058 : bStocks 출시 후 누적 거래 400억 달러 초과, 일평균 3억 달러 초과(2026-10-15 회사 발표) : https://www.prnewswire.com/news-releases/binances-bstocks-become-the-fastest-tokenized-equity-product-to-surpass-1-billion-in-assets-under-management-302909927.html
- 가설 판단 : 1등 집중. 은행, 자문, 비상장 같은 다른 업을 붙이지 않고, 새 자산(주식)도 거래소 상품(현물쌍, 담보, 무기한선물)으로만 더함. 단 "거래량 기준 세계 최대"는 회사 주장(단일 출처) [F-0676][F-0062][F-1231]
- 자기 점검
  - 다른 회사 이름으로 바꿔도 맞나 : 아님. Kraken도 실물 주식과 주식 토큰을 팔지만 실물은 미국 고객, 토큰은 미국 밖 고객으로 대상이 다름. 같은 이용자에게 실물을 먼저 열고 1:1 전환 토큰을 얹은 것은 Binance만 해당
  - 연혁 요약인가 : 아님. 왜(주식 거래 초기 수요)와 무엇이 다음을 열었나(같은 이용자, 1:1 전환)가 들어 있음
  - 금지 요소 : 없음(증서, 신탁 같은 상품 법적 구조와 제재는 넣지 않음)

### 후보 B
- 축 문장 : 아부다비 한 관할에서 거래소, 청산소, 중개 인가를 직접 받아 그룹의 규제 거점으로 삼고, 거기서 미국을 뺀 100여 개국 거래소 이용자에게 미국 주식 7,000종과 bStocks를 파는 역외 종합 거래 그룹이 됨
- 받치는 사실
  - F-1071 : Teng(공동 CEO), ADGM 인가가 규제 명확성과 정당성을 줘 ADGM에서 글로벌 사업을 지원한다고 발언(2025-12-08) : https://tools.prnewswire.com/en-us/live/20813/release/20251207EN41035
  - F-1418 : ADGM 활성 인정기관 3곳 중 2곳(Nest Exchange, Nest Clearing and Custody)이 Binance 계열 : https://www.adgm.com/public-registers/fsra/firms
  - F-0054 : bStocks는 미국과 미국인 제외, 허용 지역 자격 이용자에게 2차 시장으로 제공 : https://www.prnewswire.com/apac/news-releases/binance-exchange-launches-bstocks-tokenized-securities-11-backing-and-247-trading-302798969.html
- 가설 판단 : 1등 집중. 나라마다 인가를 늘리기보다 거점 한 곳에 인가를 모으고 같은 거래소로 판매 [F-1071][F-1418]
- 자기 점검
  - 다른 회사 이름으로 바꿔도 맞나 : 일부 겹침. Coinbase도 ADGM에서 주식 토큰을 내므로 "ADGM 거점"만으로는 구분 안 됨. 거래소와 청산소 인가를 함께 쥔 점(3곳 중 2곳)으로 구분
  - 연혁 요약인가 : 아님. 왜(규제 명확성과 정당성, 회사 발언)는 있음. 다만 이 거점이 이용자 수나 거래를 얼마나 늘렸는지는 이어 주는 근거가 없음
  - 금지 요소 : 주의. 이 거점을 고른 배경에 미국 합의와 제재를 붙이기 쉬우나 축에는 넣지 않음
