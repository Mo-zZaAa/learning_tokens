# KR-1 노트 (열람 2026-11-16)

## 기준 버전
- 자본시장법: 시행 2026.11.13, 법률 제21647호(2026.5.12 일부개정). 제4조제1항은 2026.2.3 개정, 제12조제2항은 2025.9.16 개정 표시.
- 시행령: 시행 2026.11.13, 대통령령 제36823호(2026.11.10 일부개정). 별표 1은 2026.3.10 개정.
- 원문은 셸 curl로 law.go.kr lsInfoR.do 본문을 받아 raw/에 저장. WebFetch는 law.go.kr DNS 실패, fsc.go.kr은 셸에서 연결 끊김.

## 핵심 발견
1. 법 조문에 "장외거래중개업"이라는 이름은 없다(본문 검색 0건). 근거는 법 제166조(장외거래 방법은 시행령 위임), 시행령 제178조의2(2025.9.23 신설), 별표 1의 2o 단위(2o-12 지분증권, 2o-14 수익증권, 비고 17).
2. 2o 단위 최저자기자본: 일반투자자 포함 60억원, 전문투자자만 30억원. 일반 투자중개업 증권 단위(2-1-1)는 40억원이지만 비고 7로 법 제78조, 시행령 제178조의2, 제179조 업무는 제외.
3. 다자간매매체결회사 단위: 투자중개업 2a-1-2 200억, 2a-4-2 100억, 투자매매업 1a-1-2 300억, 1a-4-2 150억. 전문투자자 대상만.
4. 거래량 한도가 두 종류: 시행령 제7조의3(경쟁매매 허용선 평균거래량 15%, 종목별 30%)과 제78조제7항(조치 발동선 5%, 종목별 10%). 둘 다 과거 6개월 평균, 거래소 시장 대비.
5. 제4조제1항의 종전 1호, 2호가 2026.2.3 삭제됨. 삭제 전 내용과 개정 이유는 미확인(개정 연혁 열람 필요).

## 못 채운 것
- 2025~2026 조각투자 장외거래소 인가 사실관계(누가 언제 인가받았나)와 금융위 보도자료: fsc.go.kr 접속 실패. blocked_links.csv 참조. 시행령 제178조의2가 그 근거인지는 조문 구조에서 추정이며 보도자료로 확인 필요.
- 시행령 제178조의2의 부칙상 시행일, 별표 17의2(시장개설 단위 및 최저자기자본)는 미열람. 거래소 허가(법 제373조의2)와 장외거래소 관계 확인 필요.
- 시행령 제15조제2항의 투자계약증권 직접 언급 없음(증권 범위 항목에 투자계약증권 없음). 투자계약증권 인가 단위는 별도 확인 필요.
