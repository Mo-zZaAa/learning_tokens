# SCOPE-4 메모
- Binance 공식 사이트(www.binance.com 공지, 블로그, 기관 페이지)는 봇 차단(405, 202 빈 응답). 공지 목록 공개 API 1회 조회만 했고(F-1160, F-1161의 근거), 전수 조회와 아카이브 경유는 하지 않음(우회 금지).
- Coinbase 공식(www.coinbase.com, investor.coinbase.com, help, blog)은 셸 403, WebFetch는 DNS 실패. NFA BASIC 검색 API 403. 열지 못함.
- SEC EDGAR는 셸 403, WebFetch DNS 실패.
- Robinhood Gold 고객군은 개인 구독이라 고객(고액자산가) 축 행을 만들지 않음. Strategies, Banking은 회사가 사모 자산관리에 빗댔을 뿐 고액자산가 한정이 아님.
- F-0209(Private Markets 충돌)는 회사 블로그 발행일이 2026-10-05라 F-1153이 대체(F-0209의 10-06은 언론 기준).
